# Calma Launcher

Launcher minimalista para Moto G9 Play, inspirado en un "clean setup":

- **Pantalla 1:** hora con alarma, mes grande con efecto eco y día.
- **Pantalla 2** (desliza a la izquierda): fecha, clima en texto, tu widget de música y saludo.
- **Pantalla de bloqueo:** hora gigante (horas rellenas, minutos con contorno), clima y batería.
- Desliza hacia arriba para buscar apps, hacia abajo para notificaciones; mantén presionado para el menú.

El APK se compila solo con GitHub Actions y aparece en *Releases*.
